# Azaliya — Portfolio

Personal portfolio of Azaliya Yagnyaeva, concept artist and 2D animator.

## Run locally

Requires Node.js 18 or later. No dependencies need to be installed.

```sh
npm start
```

Open http://localhost:3000. Run `npm run check` to check JavaScript syntax.

## Files

- `index.html`: page structure and navigation.
- `styles.css`: responsive layout, custom cursors and effects.
- `script.js`: artwork metadata, scroll animation, silhouette light rays, project pages, About and Contact interactions.
- `assets/`: portfolio and process images, photo and branding.
- `resume/`: downloadable original DOCX resume.
- `fonts/`: local fonts.

This is a static website. Deploy the repository root to any static host. GitHub Pages can serve it from the main branch / root directory. Email copying requires HTTPS or localhost.

Artwork metadata and process sections are in the DATA constant in script.js. Paths are relative, so the site also works under /portfolio/.
